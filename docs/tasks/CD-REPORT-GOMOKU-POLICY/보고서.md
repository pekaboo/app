# 고양이 오목 방침 정정

한국어 단일 페이지를 8개 언어로 확장하고 광고 사업자를 Unity LevelPlay·Unity Ads로 정정했다. 자체 첫 실행 동의 카드, 선택 전 SDK 미시작, 개인화 거절과 설정 재선택을 설명한다. 특정 앱 버전부터 적용한다는 문구는 없다.

Google Play Games 선택 연결·클라우드 저장·업적과 Firebase 익명 온라인 대전·랭킹은 유지했다. 게임 main 소스에서 서버 오류 신고 기능이 확인되지 않아 해당 절은 만들지 않았다. Android 자동 백업 허용과 광고 동의의 Saved Games 제외를 구분했다.

구현 근거는 Windows Gomoku HEAD `fa88c5da3dac31e731f00a57cd77c0d9b8beb8fc`의 AdConsent.kt, AdConsentCard.kt, LevelPlayAdManager.kt, AndroidManifest.xml 및 앱 의존성이다. 게임 구현은 변경하지 않았다.

Codex 문서 작업자가 8개 언어 JSON·정적 페이지·생성기를 작성하고 Codex 부반장이 기존 정책 보존 및 변경 범위를 검수했다. 검토 중 클라우드 저장 제외 설명이 Android 백업까지 제외하는 것으로 읽히지 않도록 8개 언어를 명확히 고쳤다.

검증: `node tools/build-cat-gomoku-privacy.mjs --check`, `git diff --check` 통과. 각 언어 11개 절, 고유 `#delete-data`, 8개 언어 상호 링크 및 필수 서비스명 확인. 공개 게시 후 HTTP 응답과 정적 파일 일치 증거는 별도 작업 상태 폴더의 최종 보고서에 보존한다.

변경 범위는 오목 방침·그 원문/생성기·이 작업 문서뿐이며 app-ads.txt·다른 게임·콘솔은 변경하지 않았다. 앱 실행·광고 송출 시험은 수행하지 않았다.
