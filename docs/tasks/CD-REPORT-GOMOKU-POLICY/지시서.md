# 고양이 오목 공개 개인정보처리방침 정정

- 현재 구현 기준으로 광고 사업자를 Unity LevelPlay·Unity Ads로 고치고, 자체 첫 실행 동의 카드와 설정 재선택을 설명한다.
- 기존 Google Play Games 및 Firebase 온라인 대전 설명을 보존한다. 실제 없는 오류 신고 서버 기능을 추가하지 않는다.
- 한국어·영어·일본어·스페인어·브라질 포르투갈어·번체 중국어·독일어·프랑스어를 제공한다.
- AdMob·Google UMP 및 특정 앱 버전부터 적용한다는 문구를 넣지 않는다.
- app-ads.txt, 게임 구현, 콘솔, 서버 코드는 변경하지 않는다.
- 생성 결과 검사, 변경 범위 검토, push, 8개 공개 페이지의 HTTP 200 및 파일 일치를 확인한다.

담당: Codex 부반장(전체 검수·게시), Codex 문서 작업자(8언어 원문·정적 페이지).
