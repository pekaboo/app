# 고양이 오목 광고 제공자 정정

고양이 오목 공개 개인정보처리방침 8개 언어에 ironSource를 Unity LevelPlay 중개 네트워크의 광고 제공자로 명시한다. 광고 절·외부 제공자 절·방침 링크 표시명과 대응 JSON 원문만 최소 수정한다.

app-ads.txt에서는 google.com DIRECT 한 줄만 제거한다. RESELLER·Unity/ironSource를 포함한 나머지 모든 줄은 순서·공백·개행까지 그대로 보존한다. 다른 게임 페이지·시스템 설정·콘솔을 변경하지 않는다. 비밀값 출력·UAC 금지.

합격 기준: 생성기 --check·diff --check 통과, 8언어 ironSource 표기·삭제 앵커·상호 언어 링크 보존, 다른 게임 변경 없음, 판매자 파일이 대상 한 줄 삭제와 정확히 일치. 한 커밋으로 push한 뒤 공개 방침 8개와 app-ads.txt HTTP 200 및 게시 파일 바이트 일치를 확인한다. 변경 전후 diff와 최종 보고서는 작업 상태 폴더에 보존한다.

작업자: Codex 부반장 직접 수행. 작은 문서·판매자 파일 정정이므로 별도 워커·기기·현황판 변경 없음.
